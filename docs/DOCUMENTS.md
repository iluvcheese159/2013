## Platform Overview

Print Cosmos is a 3D printing marketplace and design platform where creators can list, sell, and share 3D models. The platform provides tools for designing, printing, and managing models, along with a community-driven marketplace.

## Design Studio

The Print Cosmos Design Studio is a web-based 3D modeling workspace built into the browser. It allows users to create, edit, and prepare 3D models for printing without installing any software.

Key features:
- Full modeling toolkit with primitive shapes (box, sphere, cylinder, cone, torus, etc.)
- Support generation and slice preview
- Direct publishing to the marketplace
- Real-time collaboration with other makers
- STL, OBJ, PLY, GLTF/GLB import and export

## Marketplace Listings

Listings are the core marketplace units. Users can create, browse, search, and filter listings.

Listing features:
- Upload 3D model files (STL, OBJ, or .pcos format)
- Set title, description, price, category, and filament color options
- Choose free, paid, or pay-what-you-want pricing
- Edit or delete listings from the My Listings section

## Thread Currency

Threads are Print Cosmos's community currency earned by:
- Posting in forums and getting upvotes
- Helping other makers and answering questions
- Creating and selling listings
- Completing daily challenges
- Joining and participating in clubs

Threads can be spent on premium features, listing boosts, or tipping creators.

## Pro Subscription

Print Cosmos Pro is the premium subscription tier with benefits including:

Discovery Clubs are subscription-based maker communities. Sellers create clubs with membership tiers at different price points. Buyers subscribe to support creators and get exclusive access.

## Messaging

Users can message other makers directly through the platform. Messages are organized by thread. Support DMs can be sent via the chat sidebar with the ⚠️ button for urgent concerns.

## Troubleshooting Common Print Issues

Bed adhesion: Clean bed with isopropyl alcohol, use glue stick or blue tape, lower first-layer temperature by 5°C.

Stringing: Increase retraction distance (1-2mm), enable combing mode in slicer.

Layer shifting: Check belt tension, tighten hotend fastener.

Under-extrusion: Clean nozzle with needle, check for filament tangles.

Over-extrusion: Reduce flow rate or temperature by 5°C increments.

## Filament Materials

PLA: Beginner-friendly, biodegradable, easy to print at 190-220°C. No heated bed required. Brittle, low heat resistance.

PETG: Durable, flexible, heat-resistant. Requires heated bed at 70-80°C. Good for functional parts.

ABS: Strong, heat-resistant, acetone-smoothable. Requires heated bed at 90-110°C, enclosure, and ventilation. For experienced users.

TPU: Flexible filament for phone cases, gaskets, soft grips. Requires direct-drive extruder and slow speeds.

## Design Studio Workflow

1. Open the 3D Designer Workshop from navigation
2. Start from scratch with basic shapes or import an existing model
3. Use toolbar to combine shapes, carve holes, add patterns
4. Set print settings (layer height, infill, supports) in right panel
5. Click Prepare for Print to generate supports and preview slice
